# What is **this**?

**This** is the most advanced solution to reduce knowledge silos. It is able to detect silos from analyzing the scenario, tools, and channels that organizations usually have.



# How to install **this**

Follow the steps below to install **this**:

1. Go to the website www.this.com
2. Click on download the agent.
3. On your console, type:
   ```sh
cd this
docker build -t <youruser>/this:${package.json.version}
```
